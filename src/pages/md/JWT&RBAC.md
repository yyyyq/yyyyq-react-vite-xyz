### JWT鉴权

#### 1. 什么是JWT
JWT（JSON Web Token）是一种无状态的身份认证机制，它允许客户端在请求时携带一个令牌，服务器通过验证这个令牌来确认用户的身份。

#### 2. JWT生成与使用
用户登录成功后，服务器会生成一个JWT令牌，并将其返回给客户端。客户端可以将这个令牌保存在本地（例如localStorage或cookie），并在每次请求时将其添加到请求头中。
  

**后端做什么？**  
每次请求：
1. 拿 token
2. 验签
3. 解出 userId
4. 确认身份，放行

### RBAC权限控制

#### 1. 什么是RBAC
RBAC（Role-Based Access Control）是一种基于角色的访问控制机制，它允许用户通过角色来获取权限，而不是直接授予用户权限。

#### 2. RBAC权限控制
RBAC权限控制通常包括以下几个步骤：
1. 定义角色：首先，需要定义不同的角色，例如管理员、普通用户等。
2. 定义权限：然后，需要定义不同的权限，例如查看、编辑、删除等。
3. 角色与权限的关联：接下来，需要将角色与权限进行关联，即定义哪些角色拥有哪些权限。
4. 用户与角色的关联：最后，需要将用户与角色进行关联，即定义哪些用户拥有哪些角色。

**后端做什么？**
1. 定义角色
2. 定义权限
3. 角色与权限的关联
请求进来： 1. 拿 token -> 2. 查询角色 -> 3. 查询权限 -> 4. 判断是否有权限
