### EventLoop 事件循环

#### 1. 事件循环是什么

JavaScript 是单线程的，但是它需要处理大量的异步任务，比如网络请求、定时器等。为了解决这个问题，JavaScript 引入了事件循环机制。

事件循环机制是指 JavaScript 引擎在执行代码时，会先执行同步任务，然后执行异步任务。异步任务会被放入任务队列中，当同步任务执行完毕后，JavaScript 引擎会从任务队列中取出异步任务并执行。这个过程会不断重复，直到任务队列为空。

#### 2. 事件循环的执行过程
  1. 执行同步代码（进调用栈）
  2. 清空微任务队列（Promise）
  3. 执行一个宏任务（setTimeout 等）
  4. 再清空微任务
  5. 循环

#### 3. 宏任务和微任务

宏任务和微任务是指异步任务的两种类型。宏任务包括定时器、I/O 操作、用户交互等，微任务包括 Promise、MutationObserver 等。

宏任务和微任务的区别在于执行时机。宏任务会在当前事件循环的末尾执行，而微任务会在当前事件循环的末尾执行，但是在下一个宏任务之前执行。

- 🟡 微任务（优先级更高）

  * Promise.then
  * queueMicrotask
  * MutationObserver

👉 特点：本轮执行完必须清空

- 🔵 宏任务
  * setTimeout
  * setInterval
  * I/O
  * UI 渲染
  * script整体代码
